

# 🛒📊 Walmart Store Sales Prediction

## 📌 Project Overview
This project focuses on building an end-to-end machine learning model to predict Walmart store sales. The goal is to analyze historical data and forecast future sales to support better inventory management and business decision-making.

---

## 🚀 Key Features
- Data preprocessing including handling missing values, outlier treatment, and data type conversion  
- Exploratory Data Analysis (EDA) to identify sales trends, seasonality, and influencing factors  
- Feature engineering using variables such as holidays, temperature, and fuel prices  
- Model training using multiple regression algorithms  
- Performance evaluation using RMSE and R² score  

---

## 🧠 Machine Learning Models Used
- Linear Regression  
- Random Forest Regressor  
- XGBoost Regressor
- Decision Tree Regressor
- SVRegressor
- KNearest Neighbour Regressor
- Gradient Boosting Regressor

👉 **Best Model:** XGBoost with ~98% R² score  

---
